# A股每日14:45量化监测与筛选系统

这是一个只读的 A 股行情监测、筛选、复盘和历史回测项目，不连接券商，不自动下单。项目已经按 `CODEX_TASK.md` 的开发顺序完成第 1～10 阶段。

## 已完成功能

完整流程仅覆盖上海主板、深圳主板、创业板，排除 ST、*ST、风险警示、退市整理、科创板和北交所。严格执行以下 12 组条件：

1. 总市值 50～200 亿元；
2. 涨幅 1%～6%；
3. 量比 1.2～1.5；
4. 换手率 5%～15%；
5. 近 3 日成交量持续放大；
6. 预计全天量/前 5 日均量为 1.05～1.50，异常爆量淘汰；
7. MA5 > MA10 > MA20；
8. 均线斜率向上且 Swing High/Low 构成 Higher High/Higher Low；
9. 价格位于 VWAP 上方的有效分钟比例不低于 70%；
10. 午后 VWAP 强度不低于 70%，且无冲高回落；
11. 相对对应指数的累计超额收益和 RS Score 达标；
12. 距离压力位不少于 3%，或为经过量价确认的有效突破。

系统还会计算支撑位、压力位、平台、缺口、成交密集价格、综合评分、A/B/C 分类、风险提示、完整淘汰原因、筛选漏斗和最接近全部条件的前 10 只。

## 真实数据源与切换机制

所有行情都来自真实公开接口，失败时切换备用源；所有源失败会直接报错，不使用缓存替代、随机数、模拟数据、前后填充或插值。

- 全市场基础行情：东方财富 → 腾讯证券 → AKShare；
- 历史日 K：腾讯证券 → 东方财富 → AKShare；
- 个股及指数分钟行情：腾讯证券 → 东方财富；
- 指数映射：上海主板→上证指数，深圳主板→深证成指，创业板→创业板指。

日 K 使用不复权价格。这样不会在历史回测中引入目标日之后才知道的复权因子；代价是除权除息附近的均线和趋势可能出现跳变，程序会保留原值而不进行人工修补。

关键单位和定义：

- `total_market_cap_cny`：人民币元；50 亿元配置为 `5000000000`；
- `change_pct`：百分点，`1.0` 表示 1%，并用 `(现价/昨收-1)×100` 复核；
- `volume_ratio`：无量纲倍数，数据源定义为当前每分钟平均成交量/过去 5 个交易日每分钟平均成交量；
- `turnover_rate_pct`：百分点，`5.0` 表示 5%；
- 成交量同时保留“手”和“股”，1 手=100 股；成交额和 VWAP 使用人民币元。

## 安装

建议使用 Python 3.10～3.13。在 PowerShell 中运行：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip install -r requirements-dev.txt
```

AKShare 是第三备用源：

```powershell
python -m pip install "akshare>=1.18"
```

## 运行

交易日 14:45～14:50 执行实时模式：

```powershell
python main.py --mode 1445
```

14:45 模式只使用 14:45 及此前分钟数据，并按已交易 225 分钟把当前成交量投影到 240 分钟；在其他时段启动会拒绝运行，防止把更晚行情混入 14:45 结果。

交易日 15:05 后执行盘后复盘：

```powershell
python main.py --mode close
```

复盘已保存的真实历史快照：

```powershell
python main.py --date 2026-08-25
```

历史日期没有基础行情快照时程序会明确失败，因为历史总市值、量比和 14:45 换手率不能从当前行情安全反推。

使用 SQLite 中逐日保存的真实快照回测：

```powershell
python main.py --backtest 2026-08-25 2026-08-25
```

回测选择阶段仅读取对应 run 保存的日 K 和截止时刻分钟线。T+1/T+2/T+3/T+5/T+10、MFE、MAE 只在之后真实数据已经入库时计算，永远不参与当日筛选。

## Windows 一键运行和计划任务

双击或在命令行运行：

```powershell
.\run_1445.bat
.\run_close.bat
```

安装工作日计划任务（14:45 实时、15:10 盘后）：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install_tasks.ps1
```

移除任务：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\remove_tasks.ps1
```

节假日没有真实行情时数据源校验会失败并停止，不生成伪结果。

## 输出

每次运行在 `results/YYYY-MM-DD/HHMM/` 生成：

- `final_candidates.csv`：最终 A/B 候选；
- `nearest_top10.csv`：最接近 12 条件的前 10 只及失败条件；
- `all_analyzed_metrics.csv`：完整指标；
- `hard_filter_eliminated.csv`：硬筛淘汰明细；
- `elimination_log.csv`：逐股票、逐阶段、逐原因日志；
- `funnel.json`、`metadata.json`；
- `screening_report.xlsx`；
- `charts/`：最终候选的日 K/MA/成交量/支撑压力图和分时/VWAP/指数对比图。

SQLite 默认位于 `database/a_stock.sqlite3`，增量保存基础行情、日 K、分钟线、指标、结果、淘汰原因和漏斗。日 K 与分钟线同时保留按 run 隔离的不可覆盖副本，防止盘后数据覆盖 14:45 状态。

## 配置

核心参数都在 `config.yaml`，包括硬筛边界、温和放量区间、异常爆量倍数、MA 周期、趋势与 Swing 窗口、VWAP 比例、RS 门槛、最小压力距离、评分权重、报告目录和数据库位置。评分权重必须合计 100。

## 真实数据验收记录

2026-08-25 是当前本地所有必要字段均有完整快照、且可重复复现的最新收盘交易日。完整流程结果：

```text
全市场 5550
→ 目标股票池 4405
→ 硬筛 22
→ 成交量 9
→ 趋势 1
→ 分时 1
→ 相对强弱 1
→ 支撑压力 0
→ 最终候选 0
```

因此结果为：`2026-08-25：无完全符合标的。` 最近的一只通过 11/12 条件，仅因距离压力位不足 3% 被淘汰。

2026-08-27 的真实盘中股票池会随停牌、风险状态和关键字段变化：09:09 首次连接得到 4,407 只，但该次只打印了汇总而未保存明细；09:20 可复现快照为 4,406 只，09:57 为 4,402 只。严格遵守不虚构原则，项目不会把后续快照的淘汰数冒充为那次未保存的 4,407 行快照。09:57 的独立失败统计为：市值 2,521、涨幅 3,580、量比 3,740、换手率 4,293，四项全部满足为 0。

## 当前已知限制

- 东方财富公开接口可能主动断开或限流，程序会记录错误并切换腾讯；
- 腾讯历史分钟接口只提供近期交易日，长期回测必须依赖每日增量保存；
- 没有保存基础快照的历史日期无法可靠重建总市值、量比和时点换手率；
- 2026-08-27 仍处于交易时段，而 2026-08-26 没有保存硬筛字段快照，所以当前最新完整复现日为 2026-08-25；
- 数据源缺少的字段写入 `NULL` 并记录问题，不跨源拼接成看似完整的数据；
- 本项目仅用于研究和观察，不构成投资建议，不连接券商交易账户。
